# Golden HEMP (GHEMP) - официальный сайт токена

## Описание
Сайт-визитка токена GHEMP, обеспеченного промышленной коноплей.
Содержит:
- Живой график цены и объём торгов
- Виджет для покупки GHEMP (USDT/TON)
- Форма заявки для инвесторов
- Дорожная карта
- Админ-панель для накрутки просмотров (доступна по паролю)

## Как запустить локально
Просто откройте файл index.html в браузере.

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub
2. Загрузите файлы
3. Включите GitHub Pages в настройках репозитория (ветка main)
